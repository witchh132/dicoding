React.js • 2 jam yang lalu

Tanya: Kena infinite loop waktu update state di dalam useEffect

Andi Darmawan

Siswa • Front-End Track

Halo teman-teman dan mentor,

Saya lagi ngerjain tugas Modul 3 bagian fitur filter data e-commerce. Niatnya mau update state `filteredProducts` pakai `setFilteredProducts` di dalam `useEffect`.

Tapi pas di-run, halamannya malah nge-hang dan tab browser langsung crash gara-gara infinite loop. Ini potongan kodenya:

useEffect(() => {
  const result = products.filter(p => p.category === selectedCat);
  setFilteredProducts(result);
}); // <-- Kira-kira saya kelewat apa ya di sini?

Kira-kira saya salah di mana ya? Udah mentok nyari penyebabnya dari tadi. Mohon pencerahannya, terima kasih! 😭

Jawaban Terbaik

Halo Andi! Wajar kok, ini emang kendala yang sering banget dialami waktu baru belajar React Hooks.

Penyebab infinite loop-nya itu karena kamu belum naruh Dependency Array di `useEffect`-nya. Kalau parameter keduanya dibiarin kosong gitu, `useEffect` bakal terus-terusan jalan tiap kali komponen me-render ulang.

Nah, karena di dalam `useEffect` kamu manggil `setFilteredProducts()`, statenya jadi berubah kan. Perubahan state ini memicu komponen buat render ulang, yang akhirnya manggil `useEffect` lagi, terus update state lagi, dan gitu terus muter-muter tanpa henti.

Solusinya simpel, cukup tambahin array di parameter kedua `useEffect` dan masukin variabel yang pengen kamu pantau perubahannya:

useEffect(() => {
  const result = products.filter(p => p.category === selectedCat);
  setFilteredProducts(result);
}, [products, selectedCat]); // <-- Tambahin array ini

Coba di-update kodenya ya. Semangat lanjut belajarnya! 🚀
